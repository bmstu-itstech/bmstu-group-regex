# bmstu-group-regex

Буквально регулярное выражение для учебной группы МГТУ им. Н.Э. Баумана.

## Как использовать?

Скопировать регулярное выражение из [regex.txt](regex.txt).

## Как обновлять?

1. Скачать html-страницу из контингента.
2. Спарсить все возможные группы.
3. Записать обновленный список групп в [groups.txt](groups.txt).
4. Исправить регулярное выражение так, чтобы [test.py](test.py) прошёл.
